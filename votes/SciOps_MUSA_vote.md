# A Vote for New Projects:  SciOps_MUSA

## Proposal

This project is Scientific AI Operator Library on MUSA.  
Moore Threads and the DeepModeling are jointly building an AI for Science operator repository (MUSA), which takes in the science-computing-specific and custom operators generated through competitions and collaborations. General-purpose operator capabilities are merged into the MUSA open-source operator library and can be reused directly within the repository, ready to use out of the box. The repository is open to the outside, and other hardware platforms can extend it with their own backends. Moore Threads contributes the publicly shareable CUDA migration and operator optimization skills to the community, for contestants and research institute teams to use directly; agent tools for science-computing operator optimization can likewise be co-built within the community.
